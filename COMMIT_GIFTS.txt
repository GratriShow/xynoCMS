feat: Implémenter le système complet de cadeaux (coupons + crédits)

Ajoute un système de gestion des cadeaux pour les clients avec support des coupons Stripe et des crédits d'abonnement.

## Base de données
- migrations/0007_gifts_system.sql: 4 nouvelles tables
  * gifts: définitions des cadeaux (type, valeur, code, expiration)
  * gift_codes: codes uniques générés par utilisateur
  * gift_recipients: suivi des destinataires et rédemptions
  * gift_audit_log: historique d'audit complet

## Admin - Gestion des cadeaux
- admin/gifts.php: tableau de bord principal
  * Liste tous les cadeaux avec statistiques
  * Formulaire de création (coupon ou crédit)
  * Support codes uniques vs code partagé
  * Stats: codes générés, envoyés, expiration

- admin/gift_detail.php: vue détaillée d'un cadeau
  * Informations complètes du cadeau
  * Liste des codes et statut de rédemption
  * Historique des destinataires
  * Audit log de toutes les actions
  * Bouton supprimer avec nettoyage cascade

- admin/gift_send.php: distribution des cadeaux
  * 3 types de destinataires:
    - Tous les utilisateurs
    - Utilisateurs avec launcher actif
    - Liste personnalisée (CSV)
  * Génération automatique de codes uniques
  * Envoi d'emails avec templates
  * Suivi des destinataires

- admin/gift_actions.php: gestionnaire d'actions
  * Action suppression avec cascade
  * Protection CSRF
  * Logging admin

## Public - Interface utilisateur
- gifts.php: page de rédemption publique
  * Affiche les cadeaux disponibles (non expirés)
  * Formulaire de saisie de code
  * Validation et prévention de doubles rédemptions
  * Notifications succès/erreur

## API
- api/gifts.php: endpoint POST de rédemption
  * Authentification JWT requise
  * Validation du code et expiration
  * Support codes uniques et codes partagés
  * Réponse JSON avec détails du cadeau
  * Logging des actions

## Sécurité
✓ CSRF protection sur tous les formulaires
✓ Authentification admin requise
✓ Authentification utilisateur pour rédemption
✓ Prepared statements pour tous les requêtes DB
✓ Génération cryptographiquement sécurisée des codes (random_bytes)
✓ Idempotence de la rédemption (prévention double-usage)

## Fonctionnalités
✓ Deux types de cadeaux:
  - Coupons: réductions 1-100% (intégration Stripe)
  - Crédits: jours ajoutés aux abonnements

✓ Génération flexible des codes:
  - Code unique partagé (usage illimité jusqu'expiration)
  - Codes uniques par utilisateur (usage unique)

✓ Ciblage des destinataires:
  - Broadcast à tous les utilisateurs
  - Filtrage par statut launcher
  - Liste manuelle (CSV)

✓ Intégration email:
  - Utilise provider Resend existant
  - Templates avec détails du cadeau
  - Lien vers page de rédemption
  - Configurable via .env.local

✓ Suivi complet:
  - Audit log avec ID admin
  - Tracking des rédemptions avec timestamps
  - Historique d'activité complet
