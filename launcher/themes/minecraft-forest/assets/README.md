# Background Image

Place your PNG background image here as `background.png`.

This image will be displayed as the main background of the launcher with a semi-transparent overlay (70% opacity).

**Recommended specifications:**
- Format: PNG
- Size: 1400x900px (or any widescreen aspect ratio)
- Transparency: Optional (overlay will be applied regardless)

The background will be stretched to cover the entire content area and centered.
